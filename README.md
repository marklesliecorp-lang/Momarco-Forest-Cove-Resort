# Momarco Forest Cove Resort

A mobile-first website foundation for Momarco Forest Cove Resort.

## Project structure

- `index.html` — landing page structure and content
- `assets/css/style.css` — responsive visual design
- `assets/js/main.js` — accessible mobile navigation and footer year

## Current stage

The first landing-page scaffold is in place. Room inventory, rates, resort photography, contact information, location details and the booking workflow will be added after the resort's confirmed information is supplied.

## Next development stages

1. Add approved resort photography, logo and verified resort information.
2. Add room listings, occupancy limits, amenities and rates.
3. Build check-in/check-out and guest selection.
4. Add server-side booking calculations and payment verification.
5. Configure hosting and domain.
